# 平台打包与组件部署

平台及个人分身的实现一起交付；部署后的业务逻辑相同，但不复制当前服务器的账户、文件、密钥或已签发身份。适用 Python 3.12/3.13。WIT 3.2.0 随包提供 Linux x86_64 的原生 wheel，生产核验使用 Linux x86_64、Python 3.13；构建另需 Node.js >=22.12 和 npm，运行安装包无需 Node.js。

从旧版升级时使用干净的虚拟环境，避免旧发行包 `wit-framework` 与新发行包 `wit` 写入同一个 Python 模块目录。按下方锁文件安装后，用 `python -c "from importlib.metadata import version; print(version('wit'))"` 核对为 `3.2.0`。

## 构建与交付

```bash
uv sync --locked
.venv/bin/python scripts/build_release.py
```

脚本先在 `frontend/` 执行 `npm ci` 与 `npm run build`，再构建 Python 包。`dist/` 包含平台 wheel、源码 tar.gz 及交付 ZIP；源码包携带 Vue 源码、依赖锁和已构建资源，wheel 携带包含离线预览资源的 dist、用户帮助、EverOS worker 与技能沙箱。缺少 Vue 构建产物时 wheel 构建明确失败。ZIP 另含匹配的 WIT 3.2.0、ACPS SDK 2.2.0、EverOS 1.5.1 依赖 wheel、Redis 客户端 wheel、项目根目录下的 `redis/` 启停脚本与配置、配置示例及 SHA256 清单。

包不含生产 `.env`、运行数据库、资料原件、模型 Key、证书、私钥、备份或当前 `.venv`。第三方资源保留许可证与来源信息。ZIP 不是完整离线镜像，其他 PyPI/系统依赖仍需部署者准备。

## 独立运行

解压交付 ZIP 后：

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install --find-links dependencies ./personal_avatar_manager-*-py3-none-any.whl
# 先创建数据库并配置本机认证，或改为自己的原生 DSN
export DATABASE_URL=postgresql:///avatar?user=avatar_app
.venv/bin/avatar-platform --host 127.0.0.1 --port 18080 --data-dir ./data
```

也可用 `.venv/bin/python -m avatar`。CLI 不自动加载任意当前目录的 `.env`，配置应通过进程环境或自己的服务管理器传入。默认安装数据目录为 `$XDG_DATA_HOME/personal-avatar-manager`（未设置时位于 `~/.local/share`）；源码默认项目 `data/`。首次根管理员密码在对应数据目录的 `initial-admin.txt`。

正式接入需要自己的 PostgreSQL、Keycloak 客户端、Registry/CA 权限、模型配置、网络地址及证书。数据库初始化与导出环境见[PostgreSQL 运行](PostgreSQL运行.md)。FastAPI 直接提供构建后的 Vue 与 API，不依赖 Docker 或 Nginx；HTTPS 按已有环境使用 Uvicorn TLS 或既有网关，个人 ACPS 使用正式 ACS 的 IP 和固定端口。

### 通过已有 Nginx 提供网页

使用 Nginx 时，在平台对应的 HTTPS `server` 中合并以下配置，按部署修改上游地址。保留原域名、TLS 和登录回调配置。Nginx 在同级重新定义 `proxy_set_header` 后会停止继承上级同类指令，合并时把现有转发头一并保留。应用为带内容哈希的 `/assets/` 设一年强缓存和 ETag，`/static/` 的固定文件名可重新验证。gzip 仅用于公共静态资源。业务 API 与附件继续使用应用返回的 `no-store`。

```nginx
proxy_cache off;
proxy_request_buffering on;
client_max_body_size 0;
gzip off;
proxy_set_header Host $http_host;

location ~ ^/(assets|static)/ {
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/css text/javascript application/javascript image/svg+xml;
    proxy_pass http://127.0.0.1:18080;
}
location = /api/chat/stream {
    proxy_buffering off;
    proxy_pass http://127.0.0.1:18080;
}
location / {
    proxy_pass http://127.0.0.1:18080;
}
```

`client_max_body_size 0` 让应用按账户配额和文件类型限制上传。开启请求缓冲时，为 Nginx 请求体临时目录预留并发上传所需空间。若网关已有 Brotli 模块，可将其压缩规则限定在同一静态资源 location。合并后执行 `nginx -t`，再按网关的发布流程重载。

### Python 沙箱依赖

安装 Deno 到当前虚拟环境的 bin 目录后，从对应版本源码运行 `.venv/bin/python scripts/prepare_sandbox.py`，预置 Pyodide、NumPy、pandas、Matplotlib 和 Pillow 的离线依赖。更新旧版沙箱后需重新运行一次。此准备步骤通过现有网络代理下载并核对锁文件的 SHA-256，后续沙箱执行保持离线。

### 可选 Redis 读缓存

源码部署通过 `run.sh` 或 `service.sh start` 自动启动项目缓存。发行 ZIP 解压后，在解压根目录运行以下命令，再从同一工作目录启动平台。

```bash
export AVATAR_REDIS_SOCKET=redis/redis.sock
chmod +x redis/service.sh
./redis/service.sh start
```

缓存优先使用本机 Redis 7，也支持已加载的 Docker 镜像 `redis:7-alpine` 或服务器已有的 ACPs Redis 7 镜像。套接字仅属主可访问；缓存以 64 MiB 为上限，按 LRU 淘汰，无磁盘快照和 AOF。停用时将配置留空、重启应用，再执行 `./redis/service.sh stop`。安装后通过 systemd 直接启动的服务可重新运行 `./service.sh install` 更新单元。自管 Redis 可填写现有套接字路径并由其所有者管理生命周期。

### 从 1.1.0 回退

缓存可单独停用。业务版本回退前，暂停新身份维护和协作任务，让当前 worker 完成身份清理及协作控制投递。停止 worker 后复查以下计数均为零，再切换匹配的旧后端和前端。有在途记录时，使用当前版本恢复对应处理并复查。

```sql
SELECT COUNT(*) FROM avatar_identity_jobs j JOIN avatar_records a ON a.user_id=j.user_id
WHERE j.action='unregister' AND a.identity_status='retired' AND j.status IN ('queued','running','waiting');
SELECT COUNT(*) FROM provision_jobs
WHERE registration_phase='identity_cleanup' AND status IN ('queued','running','waiting');
SELECT COUNT(*) FROM agent_protocol_controls WHERE status IN ('queued','running');
SELECT COUNT(*) FROM agent_wire_results WHERE state='working';
```

跨存储格式回退须恢复迁移前同批数据库、旧本地存储、主密钥、原件与身份材料，并核对切换后新增的任务和回执。详见[迁移与恢复](PostgreSQL运行.md)。对结果未确认的 EverOS 写入或已发出的付费模型调用，先人工核对远端记录，再决定是否重试。

## WitComponent 嵌入

```python
import asyncio
from wit import WitAgent
from avatar.component import AvatarPlatformComponent, PLATFORM_APP

async def main():
    agent = WitAgent()
    agent.install(AvatarPlatformComponent(
        host='127.0.0.1', port=18080,
    ), required=True)
    try:
        await agent.start()
        await asyncio.Event().wait()
    finally:
        await agent.stop()

asyncio.run(main())
```

示例从宿主进程环境读取 `DATABASE_URL`，可通过 `AVATAR_DATA_DIR` 选择私有目录。宿主可通过 `PLATFORM_APP` 获取 ASGI。`serve_http=False` 不占 Web 端口，由宿主挂载应用，但平台组件仍管理 lifespan；不要重复进入或用多个组件打开同一数据目录。关闭组件会停止监听器和后台工作。以上代码即组件接入示例，不再单独维护 examples 脚本。

## 系统依赖与验收

DOC/Word 图片使用 LibreOffice 与 libseccomp2；PDF/OCR 使用 Poppler、Tesseract 和语言包；音视频使用 ffmpeg/ffprobe。可安装系统工具，或运行交付的 `.venv/bin/python install_runtime.py office` / `ocr`；源码对应 `scripts/install_runtime.py`。安装目标是当前 Python 环境的 `share/avatar-office` 或 `share/avatar-ocr`。缺失时明确报告或标记不完整，不在请求中自动下载。

```bash
export TEST_POSTGRES_URL=postgresql:///avatar_test  # 已创建的专用测试库
.venv/bin/python scripts/run_tests.py --jobs 4 unit -q
```

交付前运行精简冒烟测试，不调用真实模型或正式 Registry。升级前成套备份数据库和私有文件，具体操作见[操作手册](操作手册.md)。
