# 术语表

按「先协议、再平台、后功能」的顺序排列，供阅读其他文档时对照。

## 协议与身份

| 术语 | 含义 |
| --- | --- |
| **AIP** | Agent Interface Point，智能体对外提供服务的接口点。管理端固定 `10000`，个人分身从 `10001`–`15000` 独占分配，路径固定 `/aip/rpc` |
| **ACS** | Agent Capability Specification，智能体的能力说明书：主体描述、能力、技能。用户可在 `/api/me/acs` 预览 |
| **AIC** | Agent Identifier Code，智能体的唯一标识码，用于按地址找分身（如头像、附件的公开路径都带 `{aic}`） |
| **ATR** | 签证/注册状态轮询流程。系统级轮询由 `AVATAR_SYSTEM_ATR_ENABLED` 控制，个人实体通过身份维护任务更新 |
| **Registry** | WIT 体系的注册中心，负责受理注册申请、审核并签发证书 |
| **签证** | Registry 审核通过后为智能体身份签发证书的结果；「端点就绪」指证书可用且 AIP 已监听 |
| **mTLS** | 双向 TLS。外部调用方在 RPC 上以客户端证书证明自己的 AIC，平台据此判断调用方身份 |
| **TaskCommand** | ACPS 的任务命令消息，携带 `taskId`、`sessionId`、`command`、`commandParams.requester`、`dataItems` 等字段 |
| **命令语义** | `start` / `continue` / `get` / `complete` / `cancel`；重复命令 ID 幂等 |
| **acps-direct** | 直接提交 Registry 的注册方式，不经过中间代理 |
| **本体（Ontology）** | 平台自身的智能体身份定义（系统本体、个人分身本体），见 `avatar_ontology` 相关模块 |

## 账号与平台

| 术语 | 含义 |
| --- | --- |
| **内部 `user_id`** | 平台内稳定的用户主键。外部身份（Keycloak issuer + sub）变化时不改它 |
| **Keycloak 绑定** | 一个 `issuer + sub` 组合唯一绑定到一个内部账号，不做手机号/学号自动合并 |
| **身份迁移** | 把历史业务账号绑定到已核验的 Keycloak 身份，通过 `/api/admin/identity-migration` 预览后提交 |
| **根管理员** | 系统初始化产生的最高权限账号，不参与 Keycloak 绑定 |
| **分身 / 实体** | 一个用户的个人智能体实例，拥有独立 ACS、证书与独占端口 |
| **平台绑定** | 把当前账号与外部平台（如小镇）入口关联起来的关系 |
| **小镇（Town）** | BUPT 小镇侧的公开访问场景：访客可匿名向他人分身提问 |
| **小镇访问额度** | 分身所有者可分别设置单访客及所有访客合计的每日公开提问次数。两项默认不限，0 暂停公开问答 |

## 对话与生成

| 术语 | 含义 |
| --- | --- |
| **生成任务** | 一次聊天回答的持久化任务，记录在 `chat_generation_jobs` 账本表 |
| **`request_id`** | 客户端为一次生成请求分配的 ID。同 ID 同内容幂等返回原任务；同 ID 不同内容返回 409 |
| **任务状态** | `queued` / `running` / `succeeded` / `failed` / `cancelled` / `indeterminate` |
| **`indeterminate`** | 结果未确认状态：任务已开始但外部调用结果无法判定，不自动重放，需显式后续操作 |
| **会话租约** | 同一会话同时只允许一个生成任务持有的锁；正常结束时归零，异常窗口最长约 480 秒 |
| **快照（snapshot）** | 提交任务时固化的输入与授权上下文；排队期间新增的资料不会扩大旧任务的权限 |
| **SSE** | Server-Sent Events，流式投递回答增量；断线后按 `request_id` 恢复 |
| **待办输入（pending）** | 会话中已提交但尚未完成的消息输入，通过 `/api/chat/pending` 查询 |
| **摘要** | 会话历史过长时自动压缩出的早期内容，与最近消息一起组装上下文 |

## 资料与检索

| 术语 | 含义 |
| --- | --- |
| **附件 / 资料** | 用户上传的文件，按多级目录组织；拖拽上传保留目录结构 |
| **上传批次** | 一次拖拽上传的集合，用 `upload-batches/{batch_id}/complete` 收尾 |
| **解析（reader）** | 把 PDF、Office、图片、音视频转成可索引文本的过程；依赖 LibreOffice、Poppler、Tesseract、ffmpeg |
| **父块 / 子块** | Unstructured 按标题切出的层级分片：父块保留章节语境，子块用于精确召回 |
| **资料向量** | PostgreSQL 中按账户、集合与记录 ID 保存的嵌入，检索时仅对已授权记录计算余弦排名。旧版 Chroma 目录用于离线迁移 |
| **BM25** | 词法（关键词）召回算法，与向量召回互补 |
| **RRF** | Reciprocal Rank Fusion，把向量召回与词法召回的名次融合成统一排序 |
| **索引工作槽** | 每账户最多 10 个并行索引/素材处理单元 |
| **索引 epoch** | 一轮索引的版本标记（`file_rag_epochs`），用于安全地整体重建与回收 |
| **来源标注** | 回答引用的出处格式：「文件名 · RAG」表示检索片段，「文件名 · 源文件」表示直接读取原件 |
| **提升（promote）** | 把会话中临时引用的文件转为正式资料库文件 |

## 人格与记忆

| 术语 | 含义 |
| --- | --- |
| **Soul** | 分身的人格与表达风格档案，与「资料（事实）」分开维护 |
| **生效 Soul** | 每个账户只有一份生效 Soul，由 `active_souls` 指针指向 |
| **六项表达特征** | Soul 构建产出：`voice`（语气）、`interaction`（互动方式）、`wording`（用词）、`appearance`（形象）、`boundaries`（边界）、`examples`（示例） |
| **问卷（questionnaire）** | Soul 构建过程中向用户收集偏好与边界的问题集 |
| **记忆树（memory tree）** | Soul 素材与结构化记忆的层级视图 |
| **EverOS** | 内嵌的风格记忆框架（`vendor/EverOS`，1.5.1，Apache-2.0），通过 `tools/everos/worker.py` 桥接 |
| **持续学习** | 只处理本人真实用户气泡，映射到封闭表达标签后写入 EverOS；不学习助手消息 |
| **封闭表达标签** | 学习时使用的固定标签集合，避免自由文本导致记忆不可比对 |

## 技能与工具

| 术语 | 含义 |
| --- | --- |
| **技能（Skill）** | 可加载的能力包，含说明、代码与资源文件 |
| **显式引入** | 上传技能暂停期间，会话无法引入技能 |
| **会话技能** | 历史会话技能授权保存在 `chat_session_skills`，暂停期间不生效 |
| **沙箱** | Python 代码的隔离执行环境，按会话授权 |
| **工具授权** | 会话级开关，决定本次生成允许调用哪些内置工具 |
| **图形缓存** | Mermaid 渲染结果缓存，避免同一图表重复渲染 |

## 协作

| 术语 | 含义 |
| --- | --- |
| **Agent 对话（dialogue）** | 两个智能体之间的一次协作，含草稿、确认、结束等阶段 |
| **意图（intent）** | 平台从消息中识别出的可确认操作，用户选择或确认后落地 |
| **Agent 会话 / 任务** | 协作过程中的上下文容器与其中的工作项 |
| **通知中心** | 汇总待确认、已完成、失败等事件的入口 |
| **对端传输（PeerTransport）** | 与其他智能体交换 ACPS 消息的通道；迟到结果由持久 `working` 状态约束 |
