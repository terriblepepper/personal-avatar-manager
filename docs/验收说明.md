# 精简验收

后端用 pytest 验证账户权限、文件操作与恢复、目录迁移、持久聊天任务和构建资源路由。Vue 组件与 API 客户端用 Vitest 验证，完整页面流程用 Playwright 验证。

```bash
uv sync --locked
# 先创建专用测试库，并授予测试角色创建 schema 的权限
export TEST_POSTGRES_URL=postgresql:///avatar_test
.venv/bin/python scripts/run_tests.py --jobs 4 all -q
.venv/bin/python scripts/run_tests.py --jobs 1 all tests/test_files.py -q
.venv/bin/python scripts/run_tests.py all --collect-only -q
```

pytest-xdist 按用例动态并行。后端测试及 Playwright 通过 `TEST_POSTGRES_URL` 创建独立 PostgreSQL schema，临时原件位于 `data/test/run-*`。退出后清理本次资源，异常中断后的回收边界见[PostgreSQL 运行](PostgreSQL运行.md)。测试不连接真实模型或 Registry。`quick` 执行发布冒烟，`unit` 筛选无需 PostgreSQL fixture 的用例，`all` 为默认全量模式。Playwright 自动调用 `scripts/run_tests.py browser-server` 启动隔离后端，测试结束后关闭服务并回收资源。

`tests/test_operations.py` 验证准备/构建脚本的 `--help` 不执行外部程序或写运行目录、OCR 安装位于当前环境，以及环境/包元数据/源码的版本优先级。平台 API 与管理 ACS 随 `AVATAR_VERSION`，个人分身 ACS 保留用户值；安装测试不下载 apt 包，发行包另做构建及安装后验证。

保留的运维脚本用于启动、构建、身份管理与依赖安装；题库导入、身份绑定等日常操作优先使用管理网页。精简后不再声称覆盖原有 750 个细项。

聊天与界面可分别运行：

```bash
.venv/bin/python scripts/run_tests.py all --jobs 4 tests/test_conversations.py tests/test_model_protocols.py \
  tests/test_react.py tests/test_agent_tools.py tests/test_peer_dialogues.py \
  tests/test_accounts.py tests/test_operations.py -q
cd frontend
npm test
npm run build
npm run test:browser
```

浏览器套件使用隔离的 FastAPI、测试账户和模拟模型，覆盖聊天刷新恢复、文件预览、管理操作与移动视口。
